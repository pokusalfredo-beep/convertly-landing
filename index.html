API quick-start

3 minutos al primer JSON

# 1. Obtené tu API key (signup → email con la key)

# 2. POST con la factura
curl -X POST https://convertly.io/v1/invoice/extract \
  -H "Authorization: Bearer ck_live_xxxxxxxxxx" \
  -F "file=@factura.pdf" \
  -F "country=auto"

# 3. Recibís JSON estructurado:
{
  "success": true,
  "invoice": {
    "country": "es",
    "document_type": "invoice",
    "invoice_number": "2025/0001",
    "issuer": {
      "name": "Telefónica de España SAU",
      "tax_id": {
        "value": "A58818501",
        "type": "CIF",
        "valid_checksum": true
      }
    },
    "subtotal": 2600.00,
    "tax_breakdown": [{"rate": 0.21, "base": 2600, "amount": 546}],
    "total": 3146.00,
    "currency": "EUR"
  }
}

Endpoints disponibles: /v1/invoice/extract, /v1/invoice/batch, /v1/invoice/to-excel
